Predictive Maintenance for Industrial Machinery¶

A Machine Learning Project¶

Goal: Predict equipment failure from sensor readings (temperature, rotational speed, torque, tool wear) so maintenance can be scheduled proactively, before a breakdown occurs.

This notebook walks through the full pipeline: data generation, exploratory data analysis, feature engineering, model training/comparison, and evaluation.

See README.md in this project for full methodology write-up and discussion.

4. Feature Engineering¶

We add physics-informed interaction features that mirror the actual failure mechanisms (heat dissipation, power failure, overstrain):

In [7]:
def engineer_features(df):
    df = df.copy()
    df["Temp_diff_K"] = df["Process_temperature_K"] - df["Air_temperature_K"]
    df["Power_W"] = df["Torque_Nm"] * (df["Rotational_speed_rpm"] * 2 * np.pi / 60)
    df["Strain"] = df["Tool_wear_min"] * df["Torque_Nm"]
    df["Wear_per_speed"] = df["Tool_wear_min"] / (df["Rotational_speed_rpm"] + 1)
    return df

df_fe = engineer_features(df)

feature_cols = ["Type", "Air_temperature_K", "Process_temperature_K",
                "Rotational_speed_rpm", "Torque_Nm", "Tool_wear_min",
                "Temp_diff_K", "Power_W", "Strain", "Wear_per_speed"]

X = df_fe[feature_cols]
y = df_fe["Machine_failure"]

categorical = ["Type"]
numeric = [c for c in feature_cols if c not in categorical]

preprocessor = ColumnTransformer([
    ("num", StandardScaler(), numeric),
    ("cat", OneHotEncoder(drop="first"), categorical),
])

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.2, random_state=RANDOM_STATE, stratify=y
)
print(f"Train: {len(X_train)}  Test: {len(X_test)}")

5. Model Training & Comparison¶

We compare three classifiers, all with class-imbalance handling enabled (class_weight='balanced' / scale_pos_weight):

In [8]:
models = {
    "Logistic Regression": LogisticRegression(max_iter=1000, class_weight="balanced", random_state=RANDOM_STATE),
    "Random Forest": RandomForestClassifier(n_estimators=300, max_depth=10, class_weight="balanced",
                                             random_state=RANDOM_STATE, n_jobs=-1),
    "XGBoost": XGBClassifier(n_estimators=300, max_depth=5, learning_rate=0.1,
                              scale_pos_weight=(y_train==0).sum()/(y_train==1).sum(),
                              random_state=RANDOM_STATE, eval_metric="logloss"),
}

results = {}
fitted = {}
roc_data = {}
pr_data = {}

for name, clf in models.items():
    pipe = Pipeline([("preprocess", preprocessor), ("classifier", clf)])
    pipe.fit(X_train, y_train)
    fitted[name] = pipe

    y_pred = pipe.predict(X_test)
    y_proba = pipe.predict_proba(X_test)[:, 1]

    report = classification_report(y_test, y_pred, output_dict=True)
    results[name] = {
        "precision": report["1"]["precision"],
        "recall": report["1"]["recall"],
        "f1": f1_score(y_test, y_pred),
        "roc_auc": roc_auc_score(y_test, y_proba),
        "pr_auc": average_precision_score(y_test, y_proba),
    }
    roc_data[name] = roc_curve(y_test, y_proba)[:2]
    pr_data[name] = precision_recall_curve(y_test, y_proba)[:2]

pd.DataFrame(results).T.round(4)

def predict_failure(air_temp, process_temp, rot_speed, torque, tool_wear, machine_type="M"):
    raw = pd.DataFrame([{
        "Type": machine_type, "Air_temperature_K": air_temp, "Process_temperature_K": process_temp,
        "Rotational_speed_rpm": rot_speed, "Torque_Nm": torque, "Tool_wear_min": tool_wear,
    }])
    X_new = engineer_features(raw)[feature_cols]
    proba = best_pipe.predict_proba(X_new)[0, 1]
    pred = best_pipe.predict(X_new)[0]
    risk = "Low" if proba < 0.2 else "Medium" if proba < 0.5 else "High"
    return {"prediction": int(pred), "failure_probability": round(float(proba), 4), "risk_level": risk}

# High tool wear + high torque -> overstrain risk
predict_failure(air_temp=300.0, process_temp=310.0, rot_speed=1400, torque=60, tool_wear=230, machine_type="L")

9. Conclusions¶

  • Random Forest / XGBoost substantially outperform Logistic Regression, confirming that failure risk is driven by non-linear interactions between sensor readings rather than any single reading in isolation.
  • The engineered Power_W, Strain, and Temp_diff_K features rank among the most important predictors — validating the domain-informed feature engineering approach.
  • Because failures are rare (~12%), precision/recall/F1 and ROC-AUC/PR-AUC are the right metrics to optimize and report — not raw accuracy.
  • See README.md for full discussion of limitations and future work (time-series modeling, multi-class failure-mode prediction, threshold tuning for cost-sensitive deployment).
